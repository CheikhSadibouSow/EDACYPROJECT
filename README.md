# **📌 Projet de Gestion Hôtelière (Hotel-Red)**  

Un système complet de gestion d'hôtel développé en JavaScript (avec d'utilisation de react pour le frontend et Node.js, Express pour le backend) et mongodb comme base de donnée. Ce projet permet de gérer les réservations, les chambres, les clients et le personnel de manière efficace.

---


## **📋 Fonctionnalités Principales**  

### **1. Gestion des Chambres**  
- ✅ **Ajout/Modification/Suppression** de chambres (numéro, type, prix, statut).  
- ✅ **Recherche filtrée** (par type, disponibilité, prix).  
- ✅ **Statut en temps réel** (disponible, occupée, en nettoyage, maintenance).  

### **2. Gestion des Clients**  
- ✅ **Enregistrement des clients** (nom, prénom, email, téléphone, pièce d'identité).  
- ✅ **Historique des réservations** pour chaque client.  
- ✅ **Notifications** (e-mail/SMS) pour confirmation de réservation.  

### **3. Réservations & Paiements**  
- ✅ **Création/Annulation** de réservations avec dates d’arrivée/départ.  
- ✅ **Calcul automatique** du prix total (en fonction de la durée et du type de chambre).  
- ✅ **Gestion des paiements** (espèces, carte, mobile money) avec facture générée.  

### **4. Dashboard Administrateur**  
- 📊 **Statistiques** (taux d'occupation, revenus mensuels).  
- 👥 **Gestion du personnel** (rôles, permissions).  
- 🔐 **Authentification sécurisée** (admin, réceptionniste).  

### **5. Autres Fonctionnalités**  
- 📅 **Calendrier des réservations** (vue jour/semaine/mois).  
- 🧹 **Gestion du ménage** (suivi des chambres à nettoyer).  
- 📲 **API REST** (pour intégration avec d’autres systèmes).  

---

## **🛠 Technologies Utilisées**  
- **Frontend** : React.  
- **Backend** : Node.js + Express .  
- **Base de données** : MongoDB.  
- **Autres** : Git, JWT (authentification), PDFKit (factures).

## **🚀 Installation & Configuration**  
1. **Cloner le dépôt** :  
   ```bash
   git clone (https://github.com/CheikhSadibouSow/EDACYPROJECT.git)
   cd hotel-red
   ```

2. **Installer les dépendances** :  

création d'un nouveau utilisateur et connexion.
   ```bash
 cd frontend, tu fais npm i, npm run build ensuite npm start
 retour a la racine , cd backend, tu fais npm i, npm start.
   ```

3. **Configurer la base de données** :  
   - Modifier `config/database.js` avec vos identifiants.  

4. **Lancer l’application** :  
   ```bash
   npm start
   ```
   *(Accéder à `http://localhost:3000`)*
